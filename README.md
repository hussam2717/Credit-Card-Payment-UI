# Credit-Card-Payment-UI
A clean and modern credit card payment form built using HTML, CSS, and JavaScript. This project focuses on user-friendly design and smooth input experience for entering card details.

## Live Demo - https://hussam2717.github.io/Credit-Card-Payment-UI/

## 🚀 Features
- Responsive and centered UI design
- Credit card number input field with placeholder formatting
- Expiry date and CVV inputs
- Cardholder name input
- Clean and minimal design
- "Pay Now" button for submission

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
┣ 📄 index.html
┣ 📄 style.css
